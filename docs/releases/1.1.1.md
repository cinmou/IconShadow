This patch fixes an issue where an Open or Save dialog could leave the editor appearing unresponsive.

- Open and Save dialogs now appear as sheets attached to the editor window.
- Repeated commands bring the existing dialog forward instead of opening another one.
- Exports preserve the source image and settings selected before choosing a save location.

Download `IconShadow-1.1.1.dmg`, open it, and drag Icon Shadow into Applications to replace the previous version.

Version 1.1.1 (Build 5). Requires macOS 14 or later; supports Apple silicon and Intel Macs. The app and DMG are Developer ID signed and notarized by Apple.

本次更新修复了打开或保存对话框可能让编辑窗口看起来卡住的问题。

- 打开和保存对话框现在附着在编辑窗口上显示。
- 重复触发命令时会将已有对话框移到前面，避免重复打开。
- 导出时保留打开保存对话框前选定的源图像和参数。

下载 `IconShadow-1.1.1.dmg`，打开后将 Icon Shadow 拖入「应用程序」，替换旧版本。

版本 1.1.1（Build 5），支持 macOS 14 及以上版本，兼容 Apple 芯片和 Intel Mac。应用与 DMG 均已通过 Developer ID 签名和 Apple 公证。
