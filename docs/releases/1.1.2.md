This update enables the macOS App Sandbox, moves ICNS generation entirely in-process, and fixes a few import and window-handling edge cases.

- Runs inside the macOS App Sandbox with user-selected file access only.
- Encodes multi-resolution ICNS files directly in memory without invoking external command-line tools or writing temporary files, and falls back cleanly when saving to external or network volumes.
- Fixes SVG imports failing when third-party apps override the `.svg` file type, and supports `.app` bundles that omit `CFBundlePackageType`.
- Reopens the editor window when clicking the Dock icon or opening files after closing the window.

Download `IconShadow-1.1.2.dmg`, open it, and drag Icon Shadow into Applications to replace the previous version.

Version 1.1.2 (Build 6). Requires macOS 14 or later; supports Apple silicon and Intel Macs. The app and DMG are Developer ID signed and notarized by Apple.

本次更新启用了 macOS 应用沙盒，改为纯内存生成 ICNS，并修复了几处导入与窗口恢复的边界问题。

- 启用 macOS App Sandbox 沙盒保护，仅访问用户主动选择或拖入的文件。

- 修复第三方软件重定义 `.svg` 类型导致 SVG 无法导入的问题，并兼容未显式声明 `CFBundlePackageType` 的 `.app` 应用包。
- 关闭窗口后点击程序坞图标、使用菜单打开文件或从访达打开图片时自动恢复主窗口。

下载 `IconShadow-1.1.2.dmg`，打开后将 Icon Shadow 拖入「应用程序」，替换旧版本。

版本 1.1.2（Build 6），支持 macOS 14 及以上版本，兼容 Apple 芯片和 Intel Mac。应用与 DMG 均已通过 Developer ID 签名和 Apple 公证。
