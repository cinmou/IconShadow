This update adds a built-in Folder Icon mode, refines the interface, and introduces a new Liquid Glass app icon.

- **Folder Icon mode:** Switch between **App Icon** and **Folder** right from the toolbar. Drop an image or `.app`, or pick from built-in SF Symbols (or type any SF Symbol name) to craft custom macOS folder icons.
- **App Logo & Native Embossed styles:** Place full-color app logos with a crisp contact shadow, or render native 3-layer embossed glyphs with adjustable **Depth** and **Threshold** controls that cleanly remove exterior shadows and rounded plate rims from `.app` icons.
- **Colors & Paper Sheet:** Choose System Default, 9 macOS folder presets (Sky Blue, Blue, Purple, Pink, Red, Orange, Yellow, Green, Graphite), or any custom color—and toggle the white **Paper Sheet** to distinguish empty vs. populated folders.
- **Apply to Folder… (`⇧⌘A`):** Apply the generated multi-resolution icon directly to any folder via the native folder picker, fully inside the macOS App Sandbox.
- **Cleaner macOS UI & New Icon:** Simplified inspector copy, icon-only toolbar actions with an **Auto / Light / Dark** preview background switcher, and a new mint-teal Liquid Glass `.icon` logo.

Download `IconShadow-1.2.0.dmg`, open it, and drag Icon Shadow into Applications to replace the previous version.

Version 1.2.0 (Build 7). Requires macOS 14 or later; supports Apple silicon and Intel Macs. The app and DMG are Developer ID signed and notarized by Apple.

本次更新新增了快速制作文件夹图标功能，精简了原生界面，并换上了全新薄荷青液态玻璃图标。

- **文件夹图标模式**：在顶部工具栏即可一键切换 **应用图标 / 文件夹**。拖入任意图片或 `.app`，或直接搜索/输入任意系统内置 SF Symbol，快速生成原生质感文件夹图标。
- **应用徽标与原生浮雕**：支持带柔和接触投影的彩色应用徽标，以及校准过的三层物理压印浮雕；新增 **阈值（Threshold）** 调节滑块，可干净去除 `.app` 外围投影与圆角底板边框，仅保留主体图形压印。
- **文件夹配色与内衬纸页**：支持系统默认、9 款官方预设色（浅天蓝、蓝、紫、粉、红、橙、黄、绿、石墨灰）与自定义取色器，并可开关 **内衬纸页（Paper Sheet）** 以区分空文件夹与有文件状态。
- **一键应用到文件夹…（`⇧⌘A`）**：在沙盒权限下直接选择目标文件夹并写入多分辨率图标，省去手动复制粘贴。
- **界面瘦身与全新图标**：按 macOS HIG 精简检查器文案，工具栏预览背景新增 **自动（Auto）** 跟随系统明暗外观，应用换装全新薄荷青双层液态玻璃图标。
