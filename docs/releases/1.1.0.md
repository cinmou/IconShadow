# Icon Shadow 1.1.0

## 简体中文

这次更新整理了界面操作，改善参数调整时的预览响应，并扩展了图标导入方式。

- **直接提取应用图标**：将 `.app` 拖入窗口，或通过文件选择器打开应用，提取它当前的 Finder 图标作为待编辑素材，不会启动或修改原应用。
- **支持更多图片格式**：新增 JPEG、TIFF、HEIC、GIF、BMP、ICO、WebP、SVG、PDF 等导入支持。AVIF、相机 RAW 等额外格式取决于 macOS 的系统解码器。动态图使用第一帧，PDF 使用第一页。
- **调整预览更流畅**：连续拖动参数时及时更新，松手后恢复清晰预览，导出保持 1024 × 1024。
- **简化界面**：背景改为一键切换明暗；右侧底部并排放置同样式的 PNG、ICNS 导出按钮；恢复默认移到预设旁边；工具栏的对比和背景按钮显示文字。
- **修复预览文字颜色**：切换画布底色时，文字随底色保持正确对比度，避免系统深色模式下浅色预览出现白字。
- **保留原文件名**：保存时仅更换扩展名，不再自动添加 `-shadow`。

下载 `IconShadow-1.1.0.dmg`，打开后将 Icon Shadow 拖入 Applications，替换旧版应用。

需要 macOS 14 或更新版本，支持 Apple silicon 和 Intel。应用与 DMG 均使用 Developer ID 签名并通过 Apple 公证。支持简体中文和英文，所有图像处理都在本机完成。

## English

This update simplifies the interface, improves preview responsiveness while adjusting settings, and expands import support.

- **Extract application icons:** Drop an `.app` into the window or select it in the file picker to edit its current Finder icon. The source app is never launched or modified.
- **More image formats:** Import JPEG, TIFF, HEIC, GIF, BMP, ICO, WebP, SVG, PDF and more. Additional formats such as AVIF and camera RAW depend on the macOS decoders installed on your system. Animated images use their first frame; PDFs use their first page.
- **Smoother adjustments:** The preview keeps updating during slider changes and returns to full clarity when you release the slider. Exports remain 1024 × 1024.
- **Simpler controls:** Switch the preview background with one click. Equally styled PNG and ICNS export buttons sit together at the bottom of the inspector, Reset to Defaults sits beside the preset, and the Compare and Background toolbar controls have text labels.
- **Correct preview text contrast:** Labels follow the canvas background independently of the system appearance, fixing white text on a light canvas in Dark Mode.
- **Keep original filenames:** Saving changes only the extension, without adding a `-shadow` suffix.

Download `IconShadow-1.1.0.dmg`, open it, and drag Icon Shadow into Applications to replace the previous version.

Requires macOS 14 or later. Supports Apple silicon and Intel Macs. Both the app and DMG are Developer ID signed and notarized by Apple. English and Simplified Chinese are supported, and all image processing happens locally.
